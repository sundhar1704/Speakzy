# Speakzy – React Native (Expo Go)  — COMPLETE app files

1. In your speakzy-native project: DELETE the old `src` folder and old `App.js`.
2. Copy `App.js` and the whole `src` folder from this zip into speakzy-native.
3. Install packages (only needed once):

   npx expo install react-native-svg @react-native-async-storage/async-storage expo-speech expo-linear-gradient react-native-safe-area-context expo-font @expo-google-fonts/inter

4. Start:  npx expo start -c      (or: npx expo start --tunnel -c)

Social login switch: src/config.js  (DEMO_SOCIAL_LOGIN)
Courses:             src/data/content.js
Colours + fonts:     src/theme.js
